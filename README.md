# AD165 - Boost User Productivity with AI Assistant Joule and Personal My Space for SAP Build Work Zone

## Description

This repository contains the material for the SAP TechEd 2026 session **AD165 - Boost user productivity with AI assistant Joule and personal My Space for SAP Build Work Zone**.

## Overview

In this hands-on session, you will explore how SAP Build Work Zone enables organizations to create modern, AI-powered digital workplace experiences. Starting from scratch, you will set up a Work Zone site, configure key features including the AI assistant Joule, integrate business content from backend systems, and build custom pages and spaces. You will then enhance those pages with UI integration cards and activate the personal My Space feature, before stepping into the end-user role to experience Joule and My Space in action.

By the end of this session you will have:
- Created and configured a Work Zone site with Joule, language, mobile, and shell bar settings
- Connected and surfaced business content through federation and channel management
- Built a custom Work Zone page and space and assigned them to a role
- Added UI integration cards to enrich your page with live business data
- Enabled My Space so end users can build their own personal landing page
- Experienced the full end-user journey, including AI-assisted interactions with Joule

## Requirements

- Access to a pre-configured SAP Build Work Zone standard edition environment (provided during the session)
- A modern web browser (Google Chrome is recommended)
- No prior experience with SAP Build Work Zone is required
